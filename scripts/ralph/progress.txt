## Project: AI Explore - LLM Streaming with Vega-Lite Visualization

## Codebase Patterns
- React + TypeScript project
- Use vega-embed or react-vega for Vega-Lite
- File handling: HTML5 FileReader API
- Streaming: setTimeout/clearTimeout with cleanup
- Error handling: graceful degradation, no crashes

## Key Files
- llm_stream_dump.jsonl (sample data)
- task_instructions.md (requirements)

## Task Overview
Build a single page "AI Explore" that:
1. Loads .jsonl dump file
2. Emulates SSE streaming (50-150ms delay)
3. Shows streaming text output
4. Extracts Vega spec from text (may be split across chunks)
5. Validates Vega spec (mark, encoding)
6. Renders Vega-Lite chart with hardcoded data

## Technical Stack
- React + TypeScript
- Vega-Lite (vega-embed or react-vega)
- No backend required
- Clean structure (hooks/utils)

## 2025-01-16 - US-002
- Define TypeScript types for SSE stream events
- Created src/types/stream.ts with StreamEvent union type
- TokenEvent: {event: 'token', data: {delta: string}}
- DoneEvent: {event: 'done', data: {usage?: {...}, [key: string]: unknown}}
- ErrorEvent: {event: 'error', data: {message: string}}
- Types match llm_stream_dump.jsonl structure
- Typecheck passes successfully
- **Learnings:**
  - Use discriminated unions for event types (event field as discriminator)
  - DoneEvent data can have flexible structure (usage is optional, allow additional fields)
  - Export types from dedicated types/ directory for better organization

- Takes array of StreamEvent objects and delay (50-150ms)
- Emits events one by one with setTimeout delay
- Returns Promise that resolves when all events are emitted
- Returns cleanup function to cancel streaming (clears timeout)
- Handles cancellation gracefully (resolves promise, doesn't reject)
- Typecheck passes successfully
- **Learnings:**
  - Use setTimeout/clearTimeout for delays in browser environment
  - Return both Promise and cleanup function for cancellation support
  - Track timeout ID to allow cleanup
  - Use cancelled flag to prevent further emissions after cleanup
  - Cleanup should resolve promise (not reject) for graceful cancellation
