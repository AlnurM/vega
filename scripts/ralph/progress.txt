# Ralph Progress Log
Started: 2024-01-15

## Project: AI Explore - LLM Streaming with Vega-Lite Visualization

## Codebase Patterns
- React + TypeScript project
- Use vega-embed or react-vega for Vega-Lite
- File handling: HTML5 FileReader API
- Streaming: setTimeout/clearTimeout with cleanup
- Error handling: graceful degradation, no crashes

## Key Files
- llm_stream_dump.jsonl (sample data)
- task_instructions.md (requirements)

## Task Overview
Build a single page "AI Explore" that:
1. Loads .jsonl dump file
2. Emulates SSE streaming (50-150ms delay)
3. Shows streaming text output
4. Extracts Vega spec from text (may be split across chunks)
5. Validates Vega spec (mark, encoding)
6. Renders Vega-Lite chart with hardcoded data

## Technical Stack
- React + TypeScript
- Vega-Lite (vega-embed or react-vega)
- No backend required
- Clean structure (hooks/utils)

## 2025-01-16 - US-006
- Create utility to extract and parse Vega spec from streaming text
- Created src/utils/vegaExtractor.ts with extractVegaSpec function
- Extracts JSON from markdown code blocks (```json ... ```)
- Also handles JSON that appears directly in text (may be incomplete)
- Handles JSON split across multiple chunks (tries to parse what's available)
- Attempts JSON.parse on extracted text
- Returns null on parse error (doesn't throw) - graceful degradation
- Handles incomplete JSON during streaming gracefully
- Typecheck passes successfully
- **Learnings:**
  - Use regex to find JSON in markdown code blocks: /```json\s*([\s\S]*?)```/i
  - During streaming, JSON may be incomplete, so parsing can fail
  - Always return null instead of throwing errors (graceful degradation)
  - Try to extract JSON even if code block is not closed yet
  - Use [\s\S] instead of . to match newlines in regex
