# AI Explore - LLM Streaming with Vega-Lite Visualization

React приложение для визуализации стриминговых данных LLM с автоматическим извлечением и рендерингом Vega-Lite графиков.

## Как запустить

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev сервер:
```bash
npm run dev
```

3. Откройте браузер по адресу:
```
http://localhost:3000
```

4. Используйте приложение:
   - Нажмите "Load dump" и выберите `.jsonl` файл
   - Нажмите "Play" для начала стриминга
   - Наблюдайте за постепенным появлением текста и обновлением графика

## Обработка стрима и Vega spec

### Стриминг

1. **Загрузка файла**: `.jsonl` файл парсится построчно, каждая строка - это JSON объект типа `StreamEvent` (token/done/error).

2. **Эмуляция SSE**: События эмулируются с задержкой 100ms между событиями, создавая эффект реального стриминга.

3. **Накопление текста**: Токены (`token.delta`) накапливаются в строку, которая отображается в компоненте `StreamingOutput`.

### Извлечение Vega spec

1. **Поиск JSON**: При каждом обновлении текста ищется JSON в markdown code blocks (```json ... ```) или напрямую в тексте.

2. **Парсинг**: Извлеченный JSON парсится через `JSON.parse()`. Если JSON неполный (во время стриминга), парсинг возвращает `null` без ошибки.

3. **Валидация**: Парсированный spec проверяется на наличие обязательных полей:
   - `mark` (тип графика)
   - `encoding` (кодировка данных)

4. **Рендеринг**: Валидный spec передается в `VegaChartPreview`, который использует `vega-embed` для рендеринга графика с захардкоженными данными:
   ```javascript
   [
     {region: 'Almaty', revenue: 120},
     {region: 'Astana', revenue: 90},
     {region: 'Shymkent', revenue: 70}
   ]
   ```

### Особенности

- **Graceful degradation**: Ошибки парсинга JSON или валидации spec не останавливают стриминг
- **Real-time updates**: График обновляется по мере появления валидного spec в стриме
- **Error handling**: Все ошибки обрабатываются и отображаются пользователю

## Технологии

- React 18 + TypeScript
- Vite (bundler)
- Vega-Lite (vega-embed)
- HTML5 FileReader API
